# Иргэний Сонор · irgen.org

*Төсвийн зарцуулалтанд иргэн бүрийн оролцоо чухал*

https://irgen.org

Юу хийдэг вэ?

- **Төсвийн зарлага** — Шилэн дансны нийтэлсэн төлбөр, гэрээг байгууллага, яам, аймаг, сумаар нэгтгэж харуулна. Гүйлгээ бүр Шилэн дансан дахь эх тайлан руугаа холбоостой.
- **Худалдан авалт** — tender.gov.mn-ийн тендерийн зар, гэрээг төсөвт өртөг ба гэрээний үнийн хамт тулгана.
- **Компани, эзэмшигч** — Нийлүүлэгч компаниудын үүсгэн байгуулагч, захирал, эцсийн өмчлөгчийг нээлттэй бүртгэлээс харуулж, нэг эзэмшигчийн компаниудыг холбоно.
- **Эрсдэлийн дохио** — Давтагдсан худалдан авалт, шинээр байгуулагдсан нийлүүлэгч, төсөв ба гэрээний зөрүү, даргатай ижил нэртэй нийлүүлэгч гэх мэт 30 орчим автомат илрүүлэгчид, Бүх эрсдлийг 0–100 аар үнэлнэ.
- **Мөнгөний урсгал** — Байгууллага, компанийн мөнгө хэнээс хэн рүү урссаныг сүлжээ, график хэлбэрээр.
- **«Сонороос асуух»** — AI ашиглахгүй асуултыг ойлгож, асуултад өгөгдлөөс шууд хариулна.
- **Иргэний мэдэгдэл** — Мэдээлэл буруу алдаатай шивсэн өгөгдөлийн хайрцагч төрийн байгууллагад мэдэгдэж болно, засварыг нээлттэй бүртгэлд тэмдэглэнэ.

## Аймаг бүрийн сайт

21 аймаг, нийслэл бүр өөрийн сайт хаягтай. Иргэн өөрийн оршин суугаа а хот, аймгийн хаягаар орж төсвийн зарцуулалт хэрхэн хийгдсэнийг хороо сумын түвшинд хянан. Бүх жагсаалт, хайлт, чат тэр аймгаар ажиллах болно.

Аймгийн самбар: он, сараар зарлага, юунд зарцуулсан, сум бүрийн дүн, томоохон нийлүүлэгч ба тэдний бүртгэлтэй хаяг, илэрсэн дохио, хамгийн том гүйлгээ, бусад аймагтай харьцуулалт хийх боломжуудтай.

## Зарчим

1. **Зөвхөн нээлттэй эх сурвалж.** Шилэн данс, tender.gov.mn, улсын бүртгэлийн нээлттэй өгөгдөл ашигласан болно.
2. **Мөр бүр эх баримттай.** Гүйлгээ, гэрээ бүр эх тайлан руугаа холбоостой; хэрэглэгч өөрөө шалгаж болно.
3. **Дохио бол гэм буруутай гэсэн үг биш.** Дохио нь нэмэлт шалгалт хийх сэжүүр; хэн нэгнийг гэм буруутай гэж дүгнэхгүй.
4. **Хувь хүний нууцлал.** Хувь хүний регистрийн дугаарыг нийтлэхгүй (`******`). Хувь хүнд олгосон төлбөрийг зөвхөн байгууллагын нийт дүнгээр харуулна. 
5. **Ижил нэрний давхцал байх боломжтой** Эзэмшигч болон даргыг нэрээр тулгадаг тул ижил нэртэй өөр хүн байж болно. Хуудас бүр дээр анхааруулга оруулсан.
6. **Давхар тоолохгүй.** Төрийн санд төвлөрүүлсэн дүн, байгууллага хоорондын шилжүүлгийг аймаг, яамны нийт дүнгээс тусад нь харуулна. Өөр улирлын тайланд давтагдсан төлбөрийг нэг удаа тоолно.
7. **Нууц засвар байхгүй.** Алдаатай мөрийг хасах, засах бүрийг шалтгаантай нь «Аргачлал» хуудсанд жагсаана. Эх өгөгдлийг өөрчлөхгүй.
8. **Хиймэл оюун дүгнэлт гаргахгүй.** Чат зөвхөн өгөгдлөөс тооцож хариулна; таамаг, зохиомол хариулт өгөхгүй.
9. **Нээлттэй аргачлал.** Дүрэм, онооны томьёо сайт дээр бүрэн тайлбартай байгаа.

## Аргачлал (товч)

1. **Татах** — Шилэн дансны тайлан, tender.gov.mn-ийн зар, гэрээ, улсын бүртгэлийн компани, эзэмшигчийн мэдээллийг татсан болно.
2. **Цэвэрлэх** — ердийнхөөс 1,000 дахин их гэх мэт илт буруу бичигдсэн дүн, давхардсан тайлан, нэг оронгоор зөрсөн регистрийг дүрмээр засна; засвар бүр бүртгэлтэй.
3. **Тулгах** — байгууллага, компанийг регистрээр нь холбож, төлбөрийг гэрээ, тендертэй тулгана.
4. **Илрүүлэх** — илрүүлэгч бүр тодорхой дүрмээр сэжигтэй мөрийг тэмдэглэнэ.
5. **Оноо өгөх (0–100)** —  давталты, холбогдох мөнгөн дүнгээр тооцож, байгууллагын хэмжээгээр ижил төрлийн байгууллагуудын дунд эрэмбэлнэ. 90-ээс дээш оноо авахад дор хаяж 2, 95-аас дээш авахад 3 өөр илрүүлэгчийн дохио шаардлагатай. Компанийн дохиог зөвхөн түүнээс бодитоор худалдан авсан байгууллагад тооцно.
6. **Шалгах** — нийтлэхээс өмнө өгөгдлийн бүрэн бүтэн байдал, нууцлалын автомат шалгалт; илрүүлэгч бүрээс түүвэр мөрийг эх баримттай гараар тулгана.

## Технологи

| Өгөгдөл бэлтгэх | Node.js (ES module, гадны сан ашиглаагүй), Python (импорт), Shell (шинэчлэх, нийтлэх скрипт) |
| Вэб (client) | HTML, CSS, цэвэр JavaScript (framework ашиглаагүй), d3.js график |
| Сервер | Ubuntu, nginx, Node.js хайлтын үйлчилгээ (systemd) |
| Сүлжээ, аюулгүй байдал | Cloudflare (CDN, DNS, хамгаалалт), SSL |
